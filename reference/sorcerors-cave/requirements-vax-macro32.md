You are to implement the game Sorcerers Cave in VAX Macro-32.
Everything you need to do this is contained in this directory.

You have previously implemented a cut-down version of the game for solitaire play on a Casio VX-4 pocket computer.

The original Sorcerers Cave game is a board game for multiple players. Initially we will implement a similar solitaire version.

Use best practices for the architecture of the game. You can use multiple source files if that makes sense. You should definitely be using subroutines to implement functionality that is reused and to divide the architecture of the application up cleanly. 

Rules: sorcerers-cave-rules.md
Reference implementation, with interpretation of the rules, design notes and implementation details: in casio-vx4-implementation directory

The application should make use of a standard 80x24 terminal screen. Use of SMG$ routines for display is recommended.

Initially write an implementation plan describing how the game will be structured, what the display will look like and how the user will interact with the game. You'll need to do some research both on the game and how to implement it in VAX Macro-32.
